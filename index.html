Resumen final

Instrucciones y criterios

1. Ingresa la nota definitiva de cada materia para cada periodo. Si tienes varias evaluaciones, usa la calculadora rápida como ayuda para promediarlas (cuando tengan el mismo peso).

2. Cada materia muestra su acumulado individual y lo que le falta para 120. Cada área muestra su propio acumulado, calculado promediando las materias de cada periodo y sumando los cuatro periodos.

3. Cuando faltan notas, el estado es provisional: «Meta alcanzada» o «En progreso». «No alcanzó la meta» solo aparece si los cuatro periodos están diligenciados.

4. Esta calculadora es orientativa y no reemplaza el boletín ni las reglas oficiales de promoción del colegio. Los valores permitidos son de 0 a 50 puntos por periodo y el mínimo anual es 120, según los criterios proporcionados para este proyecto.

Privacidad: no hay cuentas, analítica ni base de datos. El nombre y las notas se guardan localmente en el dispositivo mediante almacenamiento del navegador. Puedes borrarlos con «Borrar notas» o exportarlos en un archivo JSON. Si compartes el dispositivo, otros usuarios del mismo navegador podrían verlos.
